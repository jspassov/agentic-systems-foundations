# Практически занятия: Git, GitHub, VS Code и ChatGPT

**Статус:** проведени, според преподавателя.  
**Контекст:** упражнения между Модул 1 и предстоящия Модул 2.

## Учебна цел

Да се изгради общ минимален практически капацитет, преди участниците да проектират собствен Framework. Git не е цел на курса, а инструмент за версионирани знания, правила и повторно използваеми работни процеси.

## Занятие 1: локална работа и Git/GitHub

Раздаден материал:

1. **Git_for_Windows_Installation_BG.pdf** — инсталиране на Git for Windows, Git Bash/PowerShell, първоначална конфигурация и проверка.
2. **Git_GitHub_Windows_BG_Quick_Guide.pdf** — Git срещу GitHub, основни команди, branches, връщане на промени и ежедневна синхронизация.

Упражнени концепции: локално repository, staging, commit, remote, push/pull, проверка на промените и работа през VS Code. Практическият резултат е възможност за локална промяна и синхронизация с GitHub.

## Занятие 2: свързване с ChatGPT

Раздаден материал:

3. **Git_GitHub_ChatGPT_Collaboration_BG.pdf** — модел Windows/VS Code/Git ↔ GitHub ↔ ChatGPT, отделна авторизация на GitHub Connector, разлики между права за четене, предложения и запис.

Преподавателят потвърждава, че всеки участник е конфигурирал собствен ChatGPT акаунт и достъп до собственото си хранилище.

## Проверими разграничения за затвърждаване

- Git ≠ GitHub; commit ≠ push; fetch ≠ pull.
- Свързан GitHub акаунт ≠ автоматично заредени инструкции от repository.
- Наличието на AGENTS.md не гарантира автоматичното му прочитане от обикновен ChatGPT Project; нужен е bootstrap в Project Instructions или изрично действие.
- GitHub metadata access ≠ доказано право за четене/запис на произволни файлове.
- Четене на Framework ≠ разрешение за автоматична промяна или публикуване.
- Всеки участник запазва личните си предпочитания за език, име на асистента и стил на комуникация.
