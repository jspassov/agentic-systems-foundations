# Agentic Systems Foundations

## Цел

Това repository (хранилище) събира концептуалната и учебната основа за разбиране, проектиране и преподаване на AI agents (агенти с изкуствен интелект) и agentic systems (агентни системи).

Проектът не е курс по конкретен tool (инструмент), framework (рамка за разработка) или платформа като n8n, LangGraph, OpenAI Agents SDK и др.

Основната цел е първо да се изгради правилният mental model (мисловен модел): LLM (голям езиков модел), agent (агент), workflow (работен процес), tools (инструменти), Skills (умения), MCP (протокол за контекст на модела), runtime (среда за изпълнение), orchestrator (оркестратор), autonomy (автономност), guardrails (защитни ограничения), trust boundaries (граници на доверие) и human approval (човешко одобрение).

## Основен преподавателски принцип

> Инструментът може да скрие сложността, но не премахва сложността.

n8n, LangGraph и останалите средства за реализация се разглеждат като implementation choices (избори за реализация), а не като заместител на архитектурното разбиране.
