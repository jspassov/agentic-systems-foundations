## Термини, за които пазим английската форма

Следните термини често е по-полезно да останат и на английски при първата употреба:

- LLM
- AI agent
- MCP
- API
- runtime
- framework
- workflow
- guardrail
- tool
- Skill
- state
- checkpoint

Причината е, че студентите ще ги срещат именно в този вид в документация, продукти и техническа литература.

## Правило за материалите

При първа употреба в съответния контекст:

> **English term (български превод / обяснение)**

След това може да се използва кратката форма, ако няма риск от двусмислие.
